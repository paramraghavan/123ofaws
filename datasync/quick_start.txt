QUICK START - Copy Files from NFS to AWS S3
================================================================================

WHAT YOU'LL ACCOMPLISH:
- Copy files from your on-premises NAS to AWS S3
- Set it up to run daily automatically
- Monitor the process easily

================================================================================
3 SIMPLE STEPS
================================================================================

STEP 1: SET UP DATASYNC AGENT (30 minutes)
─────────────────────────────────────────
1. Launch small EC2 instance (t3.micro is fine)
2. SSH into EC2
3. Download and install DataSync Agent:

   cd /opt
   sudo wget https://s3.amazonaws.com/aws-datasync/latest/aws-datasync-agent-linux.tar.gz
   sudo tar xzf aws-datasync-agent-linux.tar.gz
   cd aws-datasync-agent
   sudo ./install.sh
   sudo systemctl start aws-datasync-agent

4. Mount your NFS:

   sudo mount -t nfs your-nas-ip:/vol/data /mnt/nfs

5. Verify it's mounted:

   mount | grep nfs
   ls /mnt/nfs


STEP 2: CREATE DATASYNC LOCATIONS (10 minutes)
───────────────────────────────────────────────
Run these AWS CLI commands:

   aws datasync create-location-nfs \
     --subdirectory /mnt/nfs \
     --server-hostname 10.0.0.50 \
     --on-prem-config AgentArns=arn:aws:datasync:us-east-1:123456789012:agent/xyz

   aws datasync create-location-s3 \
     --s3-bucket-arn arn:aws:s3:::my-data-bucket \
     --s3-config BucketAccessRoleArn=arn:aws:iam::123456789012:role/datasync-s3-role

SAVE THE ARNs FROM THE OUTPUT!


STEP 3: COPY FILES (Choose one)
───────────────────────────────

OPTION A - ONE-TIME COPY (Right now)
─────────────────────────────────────
1. Edit copy_now.py:
   - Add your NFS_ARN
   - Add your S3_ARN

2. Run:
   pip install boto3
   python copy_now.py

3. Watch the progress!


OPTION B - DAILY AUTOMATIC COPY (Set and forget)
─────────────────────────────────────────────────
1. Follow instructions in DEPLOYMENT.md

2. Lambda runs at 2 AM daily

3. Files copy automatically

================================================================================
PROBLEMS?
================================================================================

Can't reach NFS?
→ Check security group allows port 2049

Agent won't start?
→ SSH to EC2, run: sudo systemctl status aws-datasync-agent

Files not copying?
→ Check NFS path exists and has files

Permission errors?
→ Check IAM roles have correct permissions
